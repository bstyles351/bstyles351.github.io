Tesla Coil

A 555-driven Tesla coil switching a 3-turn primary against a 350-turn secondary.

In Progress

Tools: KiCad

Core Problem

This self-guided project challenged me to use MOSFETs as switching devices and wind my own inductors.

Technical Contributions

  • I created a simple circuit that would create a good size Tesla coil that should produce good size sparks.
  • KiCad was used for the design and the intention was to eventually create a PCB.
  • I used a drill press to create holes in a PVC pipe to create the tall inductor.

Design Choices

For this project I challenged myself to use only components that were readily available in the undergraduate circuits lab, this naturally led me to use a 555 timer and a IRFZ44N MOSFET. These components are easy to come by and often well stocked in electronics labs. A potentiometer was used to allow for tunability of the 555 timer so that resonance could be achieved and the fun wireless power transfer would occur. Unfortunately, I was unable to find the resonant frequency and it either is outside of the potentiometer range or there are bugs in my circuit. I plan on using a function generator to find the resonant frequency and move the design from a bread board to a perfboard to reduce noise and potential for external impedance.

Results

Currently, I have been unable to find the resonant frequency, my plan is to eventually purchase a function generator so that I can sweep all frequencies and find my needle in a haystack!
