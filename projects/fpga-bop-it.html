FPGA Bop-it

Final project for logic design, a custom project imagined by my lab partner and me.

Tools: Vivado, Nexys A7

Core Problem

We sought to recreate a Bop-it using as many inputs we could on an FPGA board for our final project in Logic Design.

Technical Contributions

  • Formulated the overall concept to recreate Bop-it for our final project for Logic Design.
  • Programmed seven-segment display to simultaneously output the score and task using only one segment input on two displays.
  • Developed code for overall game logic using a psuedo random number generator and state machines.

Design Choices

With guidance from our professor we set the parameters for the project as follows:The FPGA generates a task randomly. The player must complete the task in a set timeframe. Each successful round decreases the time you have in order to complete the next task. Our inputs included 1 Button, 1 Switch, microphone, reset button, accelerometer. Our outputs used All LEDs and the 7-Segment Display. The defining features of our game included: The FPGA must generate a random task. The system must display the task and score. The player must complete the task in the time constraint. Each successful round must increment the score and decrease the time to complete the next task. LEDs will count down from left to right to show time remaining on the current task. If the timer runs out or the wrong task is completed the game is over. Overall this project was a huge success. I was very proud of how fun the game was to play and how great it felt to play!

Results

  • We received a grade of 107 on the project.
  • While doing our demo the TA had other TAs come to try out our game.
