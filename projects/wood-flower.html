The Flower Series

A series of laser cut wood flowers.

Tools: OnShape, Laser Cutter

Core Problem

A self defined challenge to recreate flowers using only a laser cutter and no mechanical connections or adhesives of any kind.

Technical Contributions

  • Designed each flower from scratch using only reference images.
  • Each flower was designed and optimized so that it can be quickly produced using only a laser cutter.

Design Choices

Creating a natural looking three-dimensional form using only two-dimensional components was inherently challenging. Additionally, CAD software tends to resist organic shapes which are inherently difficult to constrain and tolerance. These aspects made designing both challenging and incredibly rewarding. Translating from image to a layout that was easy to assemble but also structurally sound was an excellent puzzle. This project helped me to further develop my CAD skills and ability to design with strict constraints. My ability to realize a design has improved in leaps and bounds.

Results

Each flower stands tall on my bookshelf and is a nice conversation piece.
